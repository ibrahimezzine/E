دليل قانوني ومفصل لاستخدام aircrack-ng

⚠️ تنبيه قانوني

يجب أن تستخدم أدوات اختبار الشبكات اللاسلكية فقط على شبكات تملك الإذن الصريح لاختبارها. أي استخدام خارج هذه الحدود يُعد مخالفًا للقانون.

ما هو aircrack-ng؟

هي مجموعة أدوات لاختبار وتقييم أمان شبكات الواي فاي. هدفها الأساسي حماية الشبكات الخاصة بك من الثغرات.

شرح إخراج الأمر iw dev

ibrahim@himo-pc:~$ iw dev phy#0 Interface wlo1 ifindex 2 wdev 0x1 addr e0:f4:42:5a:ec:f8 type managed channel 1 (2412 MHz), width: 20 MHz, center1: 2412 MHz txpower 15.00 dBm multicast TXQ: qsz-byt qsz-pkt flows drops marks overlmt hashcoltx-bytes tx-packets 0 0 0 0 0 0 0 00
  • wlo1: اسم كرت الشبكة اللاسلكي
  • type managed: وضع الاتصال العادي
  • channel: القناة الحالية
  • addr: عنوان MAC

خطوات إعداد مختبر آمن وقانوني

  1. أنشئ شبكة وهمية أو استخدم جهاز راوتر خاص بك.
  2. ضع كرت الشبكة في وضع monitor فقط داخل مختبرك.
  3. التقط الحزم وادرسها لتحسين أمان شبكتك.
  4. لا تستهدف أي شبكة خارجية.

نصائح أمنية

  • استخدم WPA2/3 فقط.
  • اختر كلمة سر قوية وطويلة.
  • حدّث أجهزة الشبكة باستمرار.
